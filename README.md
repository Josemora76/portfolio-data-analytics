## Herramientas

- Power BI
- SQL
- Excel
- Análisis y visualización de datos

## Proyecto 1 - Reporte de Ventas en Power BI

Proyecto desarrollado para analizar la evolución de las ventas y su distribución por categoría mediante Power BI.

El trabajo incluye preparación y modelado de datos, construcción de reportes visuales, filtros, jerarquías temporales y funcionalidades de drill-through para facilitar el análisis de la información y la toma de decisiones.
